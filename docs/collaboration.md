# Using the shared archive

Give your AI the repository link and ask it to read TEAM_CONTEXT.md and AGENTS.md first. It can then retrieve the match, trial and strategy files it needs. No extra project setup is required to read or download the data.

Agents share knowledge by reading these files and contributing cited findings. Connecting GitHub does not automatically retrain model weights or synchronize separate chat memories.

When adding another match, preserve its original export, add its match ID and available evidence to the index, and label unknown details as unknown. Keep credentials out. When adding an idea or test result, identify the strategy and conditions and retain unsuccessful outcomes too.

The existing strategy code and scripts are historical reference snapshots. Some old working scripts retain paths from their original workspace. No new bot is created by this archive.
